# 日本の物価指標分析プロジェクト

日本の主要な物価指標（GDPデフレータ、CPI、企業物価指数、企業向けサービス価格指数）の推移を収集・分析し、系列間の定性的な違いを明らかにするプロジェクトです。

## 📊 プロジェクト概要

このプロジェクトでは、以下の8つの物価指標を分析対象としています：

1. **CPI（消費者物価指数）**
   - CPI総合
   - CPI生鮮食品除く（コアCPI）
   - CPI食料エネルギー除く（コアコアCPI）

2. **GDPデフレータ**

3. **企業物価指数（CGPI）**
   - 国内企業物価指数
   - 輸出物価指数
   - 輸入物価指数

4. **企業向けサービス価格指数（CSPI）**

### 分析期間
1990年1月 〜 2024年12月（月次データ）

## 🚀 使い方

### 1. 環境セットアップ

```bash
# 依存パッケージのインストール
pip install -r requirements.txt
```

### 2. データ収集

```bash
# サンプルデータの生成
python scripts/data_collector.py
```

**注意**: このスクリプトは、実際の日本の物価動向に基づいたサンプルデータを生成します。実際のデータを使用する場合は、以下のソースからデータを取得してください：

- **e-Stat（政府統計の総合窓口）**: https://www.e-stat.go.jp/
- **日本銀行時系列統計**: https://www.stat-search.boj.or.jp/

### 3. 分析・可視化の実行

```bash
# 分析と可視化の実行
python scripts/analyze_visualize.py
```

実行すると、`output/` ディレクトリに以下のファイルが生成されます：
- 各種グラフ（PNG形式）
- 要約統計量（CSV形式）

### 4. 分析レポートの確認

詳細な分析結果は `ANALYSIS_REPORT.md` をご覧ください。

## 📈 主要な分析結果

### ボラティリティ（変動の大きさ）

各指標の標準偏差（前年比変化率）：

| 順位 | 指標 | 標準偏差 |
|-----|------|---------|
| 1 | 輸入物価指数 | 2.90% |
| 2 | 輸出物価指数 | 2.10% |
| 3 | 国内企業物価指数 | 2.05% |
| 4 | CPI総合 | 1.69% |
| 5 | CPI生鮮食品除く | 1.56% |
| 6 | CSPI | 1.39% |
| 7 | GDPデフレータ | 1.32% |
| 8 | CPI食料エネルギー除く | 1.27% |

**解釈**: 輸入物価指数が最も変動が大きく、為替や国際資源価格の影響を強く受けることがわかります。一方、基調的な物価を示すコアコアCPIは最も安定しています。

### 系列間の主な違い

1. **対象範囲の違い**
   - CPI: 家計が購入する財・サービス（輸入品含む）
   - GDPデフレータ: 国内生産の全ての財・サービス（輸入品除く、輸出品含む）
   - CGPI: 企業間で取引される財（輸入品・輸出品含む）
   - CSPI: 企業間で取引されるサービス

2. **価格の硬直性**
   - 財（CGPI）: 変動しやすい（原材料価格、為替の影響）
   - サービス（CSPI）: 硬直的（賃金依存、長期契約）
   - 消費者価格（CPI）: 中間（企業が価格変動を部分的に吸収）

3. **為替の影響度**
   - 輸入物価指数 > CPI > GDPデフレータ
   - GDPデフレータは輸入品を含まないため、為替の直接的影響が小さい

4. **波及の時間差**
   - 企業物価指数 → 消費者物価指数 → サービス価格指数
   - 原材料価格の変動が、数ヶ月の時間差で消費者価格に波及

## 🔍 主要な発見事項

### 2022年以降の物価上昇の特徴

1. **輸入物価主導**: エネルギー価格高騰と円安により、輸入物価が大幅上昇
2. **価格転嫁の進展**: 企業物価の上昇が消費者物価に波及
3. **コアコアCPIの上昇は限定的**: 賃金上昇を伴う構造的なインフレには至っていない

### GDPデフレータとCPIの乖離

- 2013年以降、両者の動きに乖離が見られる
- 主因: 為替の影響度の違い、輸出品価格の動向
- 円安時: CPI上昇 > GDPデフレータ上昇（輸入物価上昇の影響）

## 📚 データソース

実際のデータを使用する場合は、以下の公的統計からダウンロードできます：

- **CPI（消費者物価指数）**: 総務省統計局
  - https://www.stat.go.jp/data/cpi/
  - e-Stat: https://www.e-stat.go.jp/

- **GDPデフレータ**: 内閣府経済社会総合研究所
  - https://www.esri.cao.go.jp/jp/sna/data/data.html

- **企業物価指数（CGPI）**: 日本銀行
  - https://www.boj.or.jp/statistics/pi/cgpi_release/
  - 時系列データ: https://www.stat-search.boj.or.jp/

- **企業向けサービス価格指数（CSPI）**: 日本銀行
  - https://www.boj.or.jp/statistics/pi/cspi_release/

### e-Stat APIの使用

実データを自動で取得する場合は、e-Stat APIの利用を推奨します：

1. APIキーの取得: https://www.e-stat.go.jp/api/
2. APIドキュメント: https://www.e-stat.go.jp/api/api-info/
