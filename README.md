# プロジェクト1: 日本の物価指標分析

## 📊 プロジェクト概要

このプロジェクトでは、以下の8つの物価指標を分析対象としています：

1. **CPI（消費者物価指数）**
   - CPI総合
   - CPI生鮮食品除く（コアCPI）
   - CPI食料エネルギー除く（コアコアCPI）

2. **GDPデフレータ**

3. **企業物価指数（CGPI）**
   - 国内企業物価指数
   - 輸出物価指数
   - 輸入物価指数

4. **企業向けサービス価格指数（CSPI）**

### 分析期間
1990年1月 〜 2024年12月（月次データ）

## 📈 主要な分析結果

### ボラティリティ（変動の大きさ）

各指標の標準偏差（前年比変化率）：

| 順位 | 指標 | 標準偏差 |
|-----|------|---------|
| 1 | 輸入物価指数 | 2.90% |
| 2 | 輸出物価指数 | 2.10% |
| 3 | 国内企業物価指数 | 2.05% |
| 4 | CPI総合 | 1.69% |
| 5 | CPI生鮮食品除く | 1.56% |
| 6 | CSPI | 1.39% |
| 7 | GDPデフレータ | 1.32% |
| 8 | CPI食料エネルギー除く | 1.27% |

**解釈**: 輸入物価指数が最も変動が大きく、為替や国際資源価格の影響を強く受けることがわかります。一方、基調的な物価を示すコアコアCPIは最も安定しています。

### 系列間の主な違い

1. **対象範囲の違い**
   - CPI: 家計が購入する財・サービス（輸入品含む）
   - GDPデフレータ: 国内生産の全ての財・サービス（輸入品除く、輸出品含む）
   - CGPI: 企業間で取引される財（輸入品・輸出品含む）
   - CSPI: 企業間で取引されるサービス

2. **価格の硬直性**
   - 財（CGPI）: 変動しやすい（原材料価格、為替の影響）
   - サービス（CSPI）: 硬直的（賃金依存、長期契約）
   - 消費者価格（CPI）: 中間（企業が価格変動を部分的に吸収）

3. **為替の影響度**
   - 輸入物価指数 > CPI > GDPデフレータ
   - GDPデフレータは輸入品を含まないため、為替の直接的影響が小さい

4. **波及の時間差**
   - 企業物価指数 → 消費者物価指数 → サービス価格指数
   - 原材料価格の変動が、数ヶ月の時間差で消費者価格に波及

## 🔍 主要な発見事項

### 2022年以降の物価上昇の特徴

1. **輸入物価主導**: エネルギー価格高騰と円安により、輸入物価が大幅上昇
2. **価格転嫁の進展**: 企業物価の上昇が消費者物価に波及
3. **コアコアCPIの上昇は限定的**: 賃金上昇を伴う構造的なインフレには至っていない

### GDPデフレータとCPIの乖離

- 2013年以降、両者の動きに乖離が見られる
- 主因: 為替の影響度の違い、輸出品価格の動向
- 円安時: CPI上昇 > GDPデフレータ上昇（輸入物価上昇の影響）

## 📚 データソース

実際のデータを使用する場合は、以下の公的統計からダウンロードできます：

  - https://www.boj.or.jp/statistics/pi/cspi_release/

# プロジェクト2: 世界の中央銀行 当座預金付利金利分析

## 📊 プロジェクト概要

世界の主要中央銀行が市中銀行の中央銀行当座預金に付利している金利（超過準備預金金利）の推移を分析します。

### 対象となる中央銀行

1. **米国連邦準備制度（FRB）** - Interest on Reserve Balances (IORB)
2. **欧州中央銀行（ECB）** - Deposit Facility Rate
3. **日本銀行（BOJ）** - 超過準備預金金利
4. **イングランド銀行（BOE）** - Bank Rate
5. **カナダ銀行（BoC）** - Deposit Rate
6. **オーストラリア準備銀行（RBA）** - Cash Rate Target
7. **スイス国立銀行（SNB）** - Sight Deposit Rate

## 🚀 使い方

### 1. 環境セットアップ

```bash
# 依存パッケージのインストール
pip install pandas matplotlib seaborn numpy pandas-datareader
```

### 2. 分析の実行

```bash
# データ収集・分析・可視化を一括実行
python scripts/central_bank_rates.py
```

実行すると、以下のファイルが生成されます：
- `data/central_bank_rates.csv`: 金利データ（CSV形式）
- `output/central_bank_rates_all.png`: 全中央銀行の金利推移グラフ
- `output/central_bank_rates_by_region.png`: 地域別比較グラフ
- `output/central_bank_rates_recent5years.png`: 直近5年間の詳細推移
- `output/central_bank_rates_heatmap.png`: 年次平均金利ヒートマップ

### 3. 分析レポートの確認

詳細な分析結果は [CENTRAL_BANK_RATES_REPORT.md](CENTRAL_BANK_RATES_REPORT.md) をご覧ください。

## 📈 主要な分析結果

### 最新の金利水準（2024年12月時点）

| 中央銀行 | 金利（%） |
|---------|---------|
| 米国（FRB） | 5.40% |
| 英国（BOE） | 5.25% |
| カナダ（BoC） | 5.00% |
| オーストラリア（RBA） | 4.35% |
| 欧州（ECB） | 4.00% |
| スイス（SNB） | 1.75% |
| 日本（BOJ） | 0.10% |

### 主要な発見事項

1. **2020年コロナショック**: 主要国が一斉にゼロ金利政策を採用
2. **2022年以降の利上げサイクル**: インフレ対応で約1年半で5%以上の急速利上げ
3. **日本の独自路線**: 2024年3月にマイナス金利を解除したが、依然として最低水準
4. **欧州・スイスのマイナス金利解除**: 長期マイナス金利から正常化へ

### 変動幅（2015年〜2024年）

| 中央銀行 | 変動幅 |
|---------|-------|
| 米国（FRB） | 5.30% |
| 英国（BOE） | 5.15% |
| カナダ（BoC） | 4.75% |
| 欧州（ECB） | 4.50% |
| オーストラリア（RBA） | 4.25% |
| スイス（SNB） | 2.50% |
| 日本（BOJ） | 0.20% |

## 📚 データソース

- **FRED (Federal Reserve Economic Data)**: https://fred.stlouisfed.org/
  - 米国連邦準備銀行セントルイス支店が提供する経済データベース
  - 世界各国の中央銀行金利データを網羅

## 🔍 分析の特徴

- **時系列分析**: 2015年以降の金利推移を可視化
- **地域別比較**: 先進国・欧州・アジア太平洋で分類
- **直近5年間の詳細分析**: 2022年以降の急速な利上げサイクルに焦点
- **ヒートマップ**: 年次平均金利の視覚化で長期トレンドを把握
